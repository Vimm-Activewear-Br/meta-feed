# meta-feed

Feed complementar do catálogo da Vimm Activewear no Meta (Facebook/Instagram).

- Arquivo lido pelo Meta: `vimm-meta-supplementary-feed.csv`
  (https://raw.githubusercontent.com/Vimm-Activewear-Br/meta-feed/main/vimm-meta-supplementary-feed.csv)
- Uma linha por variante (ID de conteúdo = ID da variante na Shopify): imagem principal quadrada,
  imagens adicionais quadradas, short_description e custom_label_0 = vimm_feed.
- Atualizado automaticamente pela rotina semanal; não edite à mão.
